# 打砖块小游戏

一个使用原生 HTML、CSS 和 JavaScript 制作的轻量级打砖块游戏。无需安装依赖，也不需要服务器，下载 HTML 文件后即可在浏览器中运行。

## 开始游戏

1. 下载 `打砖块小游戏.html`。
2. 使用 Chromium、Chrome、Edge 或其他现代浏览器打开文件。
3. 选择难度，点击游戏区域或按空格键发球。

## 难度设置

| 难度 | 砖块数量 | 说明 |
| --- | ---: | --- |
| 简单 | 16 块 | 4 列 × 4 行 |
| 普通 | 32 块 | 8 列 × 4 行 |
| 困难 | 64 块 | 8 列 × 8 行 |

## 操作方式

### 电脑

- `←` / `→`：左右移动挡板
- `A` / `D`：左右移动挡板
- `空格`：发球或继续游戏

### 手机和平板

- 在游戏区域内触摸并左右拖动，控制挡板。
- 也可以使用游戏区域下方的左右方向按钮。

## 游戏规则

- 控制挡板反弹小球，击中并消除所有砖块。
- 每消除一块砖块获得 **10 分**。
- 玩家初始拥有 **3 条生命**。
- 小球掉出游戏区域会损失一条生命。
- 清除全部砖块即可通关；生命耗尽则游戏结束。
- 点击“重新开始”可以重置当前难度的游戏。
- 选择其他难度会立即开始新的一局。

## 技术说明

- HTML5 Canvas：绘制游戏画面、挡板、小球和砖块。
- CSS：负责页面布局、配色和移动端适配。
- 原生 JavaScript：实现碰撞检测、键盘与触摸控制、计分和游戏状态。
- 不依赖第三方库或在线资源。

## 运行环境

支持现代浏览器。游戏可以直接以本地 HTML 文件的方式打开，也可以部署到 GitHub Pages 等静态网站托管服务。
